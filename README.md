# SSO (Single Sign-On) — removed from the catalog

This repository used to profile **SSO (Single Sign-On)** as an API provider. It is not one: SSO (Single Sign-On) is an
authentication **standard**, not a company. The profile's APIs were placeholders on
`example.com` hosts with nothing behind them to call.

It was removed on **2026-09-22** as a catalog-hygiene correction
([api-evangelist/roadmap#476](https://github.com/api-evangelist/roadmap/issues/476)).
Nobody requested it; nothing about any company was published here.

- **What remains:** this notice only. There is no provider page and no rating.
- **Where the topic lives now:** as a tag on [APIs.io](https://apis.io/tags/), attached to
  the real identity providers that implement it.
- **Registry:** the slug is in `api-search/network/_data/delisted.yml`, which stops every
  harvest and enrichment pipeline from re-creating the record.
