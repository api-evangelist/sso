OASIS and the OpenEoX TC are pleased to announce that OpenEoX Core Schema Version 1.0 CSD01 is now available for public review and comment. The OpenEoX Core Schema defines the core schema for the OpenEoX unified machine-readable approach to managing and sharing General Availability (GA), End-of-Sales (EoS), End-of-Life (EoL), and End-of-Security-Support (EoSSec) information.
